# Eine Reise nach Deutschland 🇩🇪

An interactive 7-day journey exploring Frankfurt, Berlin, and Munich, built as a project-based learning assignment for German language coursework.

## 🚀 Live Demo
You can view the live website hosted on GitHub Pages:
[https://husniemubarak08-cyber.github.io/German_Project/](https://husniemubarak08-cyber.github.io/German_Project/)

## 🛠️ Tech Stack
* **Frontend:** HTML5, Tailwind CSS, JavaScript (Custom single-page application switcher)
* **Design & UI:** Glassmorphism effects, responsive flexbox layout, custom embedded YouTube background video loop.
* **Hosting:** GitHub Pages
